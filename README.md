# Proportionalität – Lerntrainer

A static HTML/CSS/JavaScript learning app for proportionality and inverse proportionality.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `.nojekyll`
3. Commit the files.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will display the public website link once Pages is published.

No npm install, server, build process, or database is required.
